      Design notes

      Notes for all six
      Design notes for this pagekept from the kit · departures

      Kept from the Electric Foundation kit

      1. The kit's web frame, unchanged: page #101013, card #1A1A1E, nested #1F1F24 (light: #F7F7F9 / #FFFFFF / #F1F1F4), and 328px market cards with radius 9 and 12px padding in a 4-column grid at 1440 with a 40px gutter.
      2. The kit's components: pill search, the category row with arrows, Yes/No outcome rows, full-width Up/Down and three-way buttons, and the bet slip with two price tiles, a Bold 32 amount, +$ chips and Confirm with ✕.
      3. The kit's card footer: "$Vol • date • category" with the gift and bookmark icons.
      4. Mono spec labels for machine facts: type, chain, collateral, market number, snapshot time.

      Deliberate departures

      1. Explorer depth the kit doesn't draw. An Etherscan-style record per market (contract, condition ID, Reality.eth question, outcome-token ERC-20s, event log, positions, resolution) and per address, built only from kit surfaces.
      2. The dot grid carries data. In the lifecycle field each column is a market and each row a step; settled steps turn from dots into crosses, so the field reads as uncertainty becoming structure.
      3. State and verification on every card. An explorer has to say where a market is in its life. Amber (waiting) and red (dispute) only ever appear next to their label.
      4. Row buttons follow the market type. The kit shows Yes/No on every row. Here a categorical No buys the other outcomes as one basket; a scalar round trades Up/Down; multi-winner markets trade Buy/Sell, because a "No" there is not one clean bet.
      5. Each price in its market's unit. #2841 reads 8.14/10 · UP 81¢, #2842 reads 50% · 6.3¢ (a funded share pays 1/8 sDAI), #2850 a default chance per year. Charts, 24h moves and ticket payouts use the same unit.
      6. Kit fixes. Binary prices add up to 100¢ (the kit's 69¢ + 37¢ is 106¢), amounts use a decimal point ("$100.00"), and sample markets use motif glyph tiles instead of photos.
      7. Type and contrast. PP Neue Montreal and Suisse Int'l Mono when installed, Geist and Geist Mono otherwise; muted text is lifted so 12px labels pass WCAG AA.
      About the data. One shared sample dataset, so the same market shows up in Deep, Futarchy, Opportunity and Risk; every address starts with 0x5eed. Only "On Seer now", the question-asker block above it and the search's "On Seer · live" rows are real: they read Seer's public markets API (the strip falls back to a dated snapshot, labelled as such). Nothing here is tradable.
